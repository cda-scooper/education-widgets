How to Use the Point Tracker Widget

  • Click ➕ Add Team to create a new team.
  • Select a point interval from the dropdown (1, 2, 5, or 10 points).
  • Use ➕ and ➖ buttons to add or subtract points.
  • Click the emoji to change it for each team.
  • Use the 👁️ icon to show or hide the controls.
  • Choose a theme to change the tracker's appearance.
